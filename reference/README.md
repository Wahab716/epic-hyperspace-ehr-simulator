# Original source reference

`original-source-reference.zip` preserves the supplied source for comparison and provenance. It is inactive and is not used by the app, tests, build or scheduler. `original-source-inventory.json` lists the archived original files with their SHA-256 hashes and active-tree disposition.

Use the repository-root npm commands, not the archived pnpm/Cloudflare scripts, to run this edition. See `docs/SOURCE-RECONCILIATION.md` for the mapping and limits. Historical verification documents inside the archive describe earlier releases and are not evidence of this release's verification.
